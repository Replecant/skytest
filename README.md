# SkyTest

Мод для Minecraft **1.21.11** на **NeoForge 21.11.x**.

## Предметы

| Предмет | Как работает | Рецепт |
|---|---|---|
| **Крюк-хват «Скелетная рука»** | ПКМ — выстрелить рукой (дальность ~40 блоков). Зацепившись за блок, она тянет вас к себе, а у цели вы повисаете. Повторный ПКМ, приседание или смена предмета в руке — отцепиться. Пока вы на крюке, урона от падения нет. Прочность 384. | `_ B B` / `_ I B` / `L _ _` (B — кость, I — железный слиток, L — поводок) |
| **Сапоги циркача** | Броня на ноги (2 ед.). Нажмите прыжок в воздухе, чтобы прыгнуть ещё раз. Двойной прыжок сбрасывает урон от падения и тратит 1 ед. прочности. | Бесформенный: кожаные ботинки + слизь + перо + красный краситель + жёлтый краситель |

Оба предмета есть во вкладке творческого режима **SkyTest**.

## Сборка

```bash
./gradlew build          # jar в build/libs/
./gradlew runClient      # запустить клиент для тестов
```

Нужна Java 21. GitHub Actions собирает jar при каждом пуше (артефакт `skytest-jar`).
